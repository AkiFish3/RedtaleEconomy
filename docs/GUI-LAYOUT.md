# GUI 布局草案（B16）

> 依据 spec v0.21 §28-29。所有面板共用同一套视觉与组件，后续 R15/R16/R17（数据驱动 UI）直接复用这份布局。
> 尺寸单位是 GUI 像素，基准 320×220（内容区 300×196，四边 10）。

## 1 视觉规范

| 项 | 值 |
|---|---|
| 面板 | 外框 `#3B2E23`，内底 `#E8DCC8`，圆角 2px |
| 边框 | `#C9A227` 2px；内阴影 1px `#2B2118` 30% |
| 文字 | 内容区 `#2B2118`；木底 `#F3EAD8`；次要信息 60% 透明度 |
| 强调 | `#C9A227`；危险 `#B4462F`；成功 `#4C7A34` |
| 字体 | 原版默认，标题 1.2×，正文 1.0×，脚注 0.85× |
| 间距 | 块间 8，行内 4，按钮内边距 6×4 |
| 交互 | hover 描边提亮 8%；按下下沉 1px；危险操作必须二次确认（R25 票据） |

## 2 组件清单

| 组件 | 高度 | 说明 |
|---|---|---|
| 标题栏 | 24 | 左标题 + 右侧关闭；可带副标题（如「3/3」） |
| 卡片 | 56 | 左侧 16×16 图标，中间两行文本，右侧 1~2 个按钮 |
| 按钮 | 20 | 宽度按内容，最小 48；禁用态 40% 灰 |
| 进度条 | 6 | 底 `#2B2118` 20%，填充按数值；可带百分比文本 |
| 滚动列表 | 可变 | 每行 18，右侧滚动条 4px，滚轮 1 行/格 |
| 物品格 | 18 | 原版 slot 背景；数量右下角 |
| 分页条 | 16 | `‹ 1/12 ›` + 中间跳页输入 |

## 4 仓库（R27）当前实现说明

仓库直接用原版 9×N 容器（`GENERIC_9X1..9X6`），不需要自绘：
行数由 `warehouse.json → rows` 决定，超过一页用 `/storage <页>` 翻页，
聊天栏会给 `[上一页] [下一页] [扩容仓库]` 可点击链接。
后续 R17 做布局拖拽时，再把它替换成自绘面板即可，数据层不用动。
