# UI 视觉规范（U6 进行中 · 供截图评审）

> 目标：**原版气质 + 更清晰的层级**，不做花哨动效。所有颜色集中在
> `client/ui/UiStyle.java`，界面里不再出现裸色值；布局类界面另有 `ui/theme.json5` 可覆盖。

## 1 层次

```
外阴影 0x66000000（四周各 4px）
 └ 面板底 #1B1B22（近乎不透明，透出一点世界画面）
    └ 面板内层 #26262F（1px 缩进，产生「内凹」感）
       ├ 顶部 1px 高光 #6E6E7A（光从上方来）
       ├ 卡片 #2E2E38 / 悬停 #3A3A46
       └ 物品格 #8B8B8B 外框 + #37373F 内凹
```

## 2 语义色

| 用途 | 值 |
|---|---|
| 主文字 | `#E8E8EE` |
| 次要文字 | `#9A9AA6` |
| 弱化文字 | `#6E6E7A` |
| 强调（金额/奖励） | `#E9C46A` |
| 成功 / 已达成 | `#7BC67E` |
| 失败 / 危险 | `#E05A47` |

规则：**一屏只有一个强调色区域**（金额或当前任务），其余用灰阶做信息分层，
避免到处都是金色导致「什么都重要 = 什么都不重要」。

## 3 已套用的界面

| 界面 | 状态 |
|---|---|
| 主入口 MainMenuScreen | ✅ UiStyle.panel + 分隔线 + 三级文字 |
| 签到 CheckinScreen | ✅ 面板 + 每天一格卡片（当前日高亮、已签绿色蒙版、点选白色描边） |
| 每日任务 TaskScreen | ✅ 面板 + 任务卡 + 铜色奖励 + 白色正文 |
| 商店 ShopScreen | ✅ 面板 + 行卡片（选中蓝 / 悬停亮）+ 物品图标 + 铜色价格 |
| 悬赏 BountyScreen（新） | ✅ 卡片 + 进度条 + 领取按钮 |
| 布局渲染 LayoutScreen | 走 `UiTheme`（深木 + 黄铜，spec §28 定的），与上面这套并存 |

> 两套配色不是失误：布局驱动的界面是「家具风」（木底黄铜），系统界面是「原版深色」。
> 如果 Aki 要统一，只需把 `UiTheme` 的默认值改成 `UiStyle` 这一套即可（一处改动）。

## 5 截图流程（U6 验收用，2026-10-20 建立）

```bat
:: 1) 放标记文件（存在才启用夹具，平时零开销）
echo. > run/u6-shots.flag
:: 2) 直接进开发存档，无人值守拍照
gradlew runClient --args="--quickPlaySingleplayer u6world"
:: 3) 图在 run/screenshots/u6-0*.png，日志在 run/u6-shots.log
:: 4) 拍完删标记，避免下次启动又自动退出
del run/u6-shots.flag
```

实现：`client/dev/UiShots`——串行打开 Hub(签到) → Hub(商店) → 任务 → 签到 → 商店，
每屏等 25 tick 再 `ScreenshotRecorder.saveScreenshot(...)`，五张拍完 `scheduleStop()`。
它只读现有界面，不写任何玩家数据。

前提：`run/config/redtale/tasks/pools/` 与 `tasks/definitions/` 里要有池与模板
（仓库里 `demo.json` 是开发用样例），否则任务页永远是空态。

## 6 首轮截图发现的问题（均已修）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 签到日历下半截画到面板外，按钮浮在日历上 | `CELL_H` 写死 30，GUI Scale 2（逻辑高 240）只有 160px 内容区 | 按内容区高度自适应 12..30，底部区块贴底边 |
| 2 | 任务屏按钮只剩文字、没有底图 | `super.render()` 先画按钮，随后 `UiStyle.panel()` 整块盖上去 | 面板/卡片先画，`super.render()` 最后画 |
| 3 | 任务卡奖励被「缴纳」按钮压住 | 奖励右对齐到 `PANEL_W-PAD-8`，按钮占 `PANEL_W-92..-12` | 奖励改对齐到按钮左边缘 −8 |
